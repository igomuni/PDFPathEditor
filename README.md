# PDFPathEditor

PDFを読み込み、Path / Text / Image を編集するElectronデスクトップツール。
元PDFが画像PDFでも Path 化し、人間がズレを微調整できるようにする。

- 元PDFは背景レイヤー(読み取り専用)として管理し、出力PDFとは分離する
- 編集結果は構造化データ(JSON)として保持し、PDF / SVG / JSON に出力する
- 当面のPoC対象: 確定申告書(案)第一表

詳細は [docs/design.md](docs/design.md) を参照。

## 開発

```sh
pnpm install
pnpm fonts      # 同梱フォント(Noto Sans JP / Noto Serif JP)を resources/fonts/ に取得
pnpm ocr:build  # macOS のみ: Vision の OCR ヘルパーをビルド(Xcode のコマンドラインツールが必要)
pnpm dev        # 開発起動(HMR)
pnpm test       # 単体テスト
pnpm build      # 型チェック + テスト + ビルド(out/)
pnpm start      # ビルド済みを起動
```

### 現状(PoC マイルストーン1)
- 「PDFを取り込む…」でPDFと作成先を選ぶと、プロジェクトフォルダ(`source/ assets/ fonts/ exports/ document.json`)を作り、指定ページを指定dpi(既定: 2ページ目・300dpi)で背景ラスターにして表示する
- ズーム: ⌘/Ctrl+ホイール、ピンチ、`+` / `-`、`1`(100%)、`5`(ページ全体)
- パン: ホイール/2本指スクロール、中ボタンドラッグ、Space+ドラッグ

### 現状(PoC マイルストーン2)
- 「罫線を検出」(⌘D)で、背景ラスターから水平・垂直の罫線と点線を検出し、「自動抽出の候補」レイヤーに Path として入れる。候補はマゼンタで背景に重ねて表示する
- 検出は候補を出すだけで、Undo/Redo できる。再実行すると候補を入れ替える
- `pnpm test` で検出器の単体テストを実行する

### 現状(PoC マイルストーン3)
- 選択: 線をクリック(Shift で追加・解除)、何もない場所をドラッグで範囲選択、⌘A ですべて選択、Esc で解除
- 微調整: 矢印キーで背景ラスターの1画素ぶん移動(Shift で10倍、Alt で 1/10)。端点のハンドルをクリックすると、その端点だけを動かせる(水平・垂直は保つ)
- 確定: Enter で選択した候補を「確定オブジェクト」レイヤーへ移す。「全件確定」(⇧⌘Enter)もある。Delete で削除
- 差分表示(⇧⌘D): 背景を赤、Pathをシアンで重ねる。一致=黒 / 背景のみ=赤 / Pathのみ=シアン
- すべての編集は Undo/Redo できる

### 現状(PoC マイルストーン4)
- 「文字を検出」(⌘T)で、背景ラスターを OCR にかけ、行ごとの Text オブジェクトを候補レイヤーに入れる。エンジンは macOS Vision と Tesseract(tesseract.js)を選べる
- 候補のサイズ・位置・字間は、インクの範囲に Noto Sans JP で組んだ文字が重なるように推定する。文字内容は人が確定する前提
- Text を選択すると右のパネルで文字列・フォント・太さ・サイズ・字間・配置・色を編集できる(Undo/Redo 対応)
- 保存すると、使っているフォントをプロジェクトの `fonts/` にコピーする

### 現状(PoC マイルストーン5)
- 「項目コードを割り当て」(⌘G)で、枠の中に単独で印字された項目コード(G01 等)を見つけ、コードの Text と右隣の枠(記入欄)の中のオブジェクトに `fieldCode` を付ける。記入欄の範囲を表すオブジェクト(線も塗りもない Path、role=inputCell)も作る
- OCR の読み違い(「GO6」「GI7」「z01」など)は正規形(G06、G17、Z01)で付ける。Text の文字列は変えない
- オブジェクトを選択すると、右のパネルで項目コードと役割を編集・解除できる。すでに付いている項目コードは、再度割り当てても上書きしない
- 選択したオブジェクトと同じ項目コードのオブジェクトを強調する。左パネルの「項目コード」タブの一覧から、コードごとにまとめて選択できる(印字・記入欄の有無、未付与の数も出る)
- 「未付与」(⇧⌘G)で、項目コードが付いていないテキストと記入欄を強調する
- 項目名ラベルへの付与は手動(1つのラベルが複数のコードにかかるため)

### 現状(PoC マイルストーン6)
- 「出力」(⌘E)で、確定レイヤーのオブジェクトをプロジェクトの `exports/` に出力する
  - `output.pdf`: PDFKit で生成。Text は実フォントのテキスト(使った文字だけをサブセット埋め込み、コピー・検索可)。「輪郭Path」を付けた Text はグリフの輪郭で描く
  - `page-NNNN.svg`: ページごとの SVG(pt、左上原点)。各要素に `id`・`data-role`・`data-field-code` を付ける
  - `output.json`: 二次利用向け。オブジェクトの一覧(外接矩形付き)と、項目コードごとの索引(記入欄の矩形など)
- 出力PDFを背景と同じ解像度でラスタライズして背景と比べ、再現率・過剰率・不一致画素率を出す(1画素のずれは許容)。結果は画面と `verify.json`、差分画像は `verify-page-NNNN-diff.png`(一致=黒 / 欠落=赤 / 過剰=シアン)
- 記入欄の範囲(線も塗りもない Path)は PDF / SVG には描かず、JSON にだけ出す

### 縦書き
- Text は横書き / 縦書きを選べる(右パネルの「向き」)。縦書きは 1 字ずつ上から下へ積み、括弧や長音は縦書き用の字形になる
- 「文字を検出」のあと、縦に並ぶ 1 字の Text(「収」「入」「金」「額」「等」)を 1 つの縦書きの Text に自動でまとめる。間に横の罫線があるもの、間隔がそろっていないものはまとめない
- 候補が背景と合っていない枠や、読み落としのある枠は、枠の中を縦の列・横の行に分けて読み直す。縦の列は、字を横 1 行に並べ直してから読む。読み直した結果は、元の候補より背景に合うときだけ採用する
- PDF / SVG / JSON 出力、確認用データ、修正ファイル(`writingMode`)も縦書きに対応

### 丸囲みの文字
- 「文字を検出」で、丸(輪)を画像から探し、中の文字を読んで候補にする
- ①〜㊿ と丸囲みのカタカナ(㋐ など)は 1 つの Text。51 以上の丸数字は、数字の Text と丸の Path(閉じた曲線)の組にする
- 罫線を検出し直しても丸は残り、文字を検出し直すと Text と丸がまとめて入れ替わる

### 読み落としの拾い直しと、手動での追加
- 「文字を検出」の最後に、どの候補にも対応しない小さなインク(1 字、記号)を 1 つずつ読み直して候補に足す。記入欄の区切りの横棒は「ー」として拾う
- 「テキストを追加」(⇧⌘T)で、表示している範囲の中央に任意のテキストを足せる。文字列・大きさは右のパネル、位置は矢印キーで直す
- 「複製」(⌥⌘D)で選択したオブジェクトを複製し、「削除」(Delete)で消す。どれも Undo できる

### マウスでの編集
- 選択したオブジェクトはドラッグで動かせる(Shift で水平・垂直に固定)。頂点のハンドルもドラッグできる
- Text をダブルクリック(または F2)すると、キャンバスの上で文字列を編集できる。Enter で確定、Esc で取り消し
- 編集中にカーソルを置くか範囲を選択して「選択範囲で分離」(⌘Enter)を押すと、そこで Text を分けられる。「結合」(⌘J)、「1字ずつに分離」(⇧⌘J)もある。どれも字の位置は変わらない
- 右クリックで、選択に対する操作のメニューが出る(編集、結合・分離、縦書き、確定、複製、削除、非表示、役割など)

### QRコード・様式ID・矢印
- 「QR・様式ID」で、背景から QRコードを見つけて Image(role=qr)として切り出し、様式ID の Text に役割を付ける。QR は元の画素をそのまま使う
- 見つからないときは「画像を切り出す」を押し、キャンバスでドラッグした範囲を Image にする
- 吹き出しの矢印(細い線 + 先端の三角形)は、「罫線を検出」で一緒に Path になる

### 複数の PDF・複数のページ
- 1 つのプロジェクトに、複数の PDF と、その中の複数のページを取り込める。ページ欄には「2」「1-3,5」の形で指定する
- 「PDFを取り込む…」は新しいプロジェクトを作る。「PDFを追加…」は開いているプロジェクトにページを足す(同じ PDF なら元 PDF は 1 つだけ持つ。取り込み済みのページは飛ばす)
- ページは左サイドバーの「ページ」一覧で切り替える。PDF の行の「+」で、PDF を選び直さずにページを追加できる。「×」でページを削除する(確認あり。元に戻せない)
- 抽出・項目コードの割り当て・全件確定・出力・確認用データは、開いているページが対象
- 保存は、目次(`document.json`)と、変更したページのファイル(`pages/<ページID>.json`)だけを書く。出力は `exports/<ページID>/` に出る
- 以前の形式(1 つの PDF・1 ページ)のプロジェクトはそのまま開ける。最初の保存で新しい構成になり、元の `document.json` は `document.v1.json` として残る

### オブジェクト一覧
- 左のサイドバーに「レイヤー → オブジェクト」の一覧を出す。種別(Path / Text / Image)、内容、項目コード、役割が見える
- 行を押すと選択し、画面の外にあればキャンバスがその位置へ移動する。キャンバスで選択すると、一覧がその行までスクロールする
- ●/○ でレイヤーやオブジェクトを個別に表示/非表示にできる(保存され、Undo できる)。非表示のものは選択されないが、出力には含まれる
- 種別・役割・項目コードの有無・文字列で絞り込み、絞り込んだものをまとめて表示/非表示にできる

### AI による確認と修正の取り込み
- 「確認用データ」(⇧⌘E)で、プロジェクトの `exports/review/` に候補の一覧(`page-NNNN-review.json`)と、背景に候補の文字を重ねたタイル画像を書き出す。取れていないインク(青枠)と、背景に合っていない Text(橙枠)に番号を付ける
- アプリの外で AI(Claude Code など)がこれを見て、修正ファイル(JSON)を作る。形式は `docs/corrections-format.md`
- 「修正を取り込む…」(⇧⌘I)で修正ファイルを選ぶと、置換・追加・削除の件数と適用できない操作を表示する。適用すると 1 回の操作として反映され、Undo 1 回で戻る
- アプリから外部の AI は呼ばない

### 最近使ったプロジェクト
- 取り込んだ・開いたプロジェクトを 10 件まで覚え、起動直後の画面、ツールバーのプルダウン、メニュー「ファイル > 最近使ったプロジェクト」から開ける
- 一覧はアプリの設定フォルダ(Electron の `userData`)の `recent-projects.json` に保存する。フォルダがなくなったプロジェクトは一覧に出さない
- ファイルダイアログは、前回使ったフォルダから始まる(PDF、プロジェクト、修正ファイルを別々に覚える。保存先は同じ設定フォルダの `settings.json`)
- 描画中にエラーが起きたときは、真っ白にせずエラーの内容と「再読み込み」を表示する
- 未保存の変更があるままウィンドウを閉じる・別のプロジェクトを開くときは、「保存 / 保存しない / キャンセル」を尋ねる
- 開発中の作業用プロジェクトは `out/projects/` に置く(`out/` は Git 管理外。ビルドで消えるのは `out/main`・`out/preload`・`out/renderer` だけ)

### 構成
- `src/main/` ファイルI/O、プロジェクト管理、PDFラスタライズと候補抽出(utility process)
- `src/main/vectorize/` Vectorizer の実装(罫線検出)
- `src/main/ocr/` OCR エンジンと後処理
- `src/main/export/` PDF / SVG / JSON の出力と差分検証
- `src/main/review/` 確認用データの書き出し(要確認箇所の洗い出し)
- `native/vision-ocr/` macOS Vision を呼ぶ Swift ヘルパー
- `scripts/` フォント取得スクリプト、実アプリの自動確認(`scripts/e2e/`、`pnpm e2e <プロジェクトフォルダ>`)
- `docs/` 設計メモ(`design.md`)、課題一覧(`backlog.md`)、修正ファイルの形式(`corrections-format.md`)
- `src/preload/` renderer に公開するAPI
- `src/renderer/` React + SVGキャンバス
- `src/shared/` ドキュメントモデルとIPCの型
